# Design System

## 1. Colour and Theme
- **Primary Color:** [e.g., #0f172a (Slate 900)]
- **Secondary Color:** [e.g., #334155 (Slate 700)]
- **Accent Color:** [e.g., #3b82f6 (Blue 500)]
- **Background:** [e.g., #ffffff (White) for light mode, #020817 (Slate 950) for dark mode]
- **Text:** [e.g., #0f172a for light mode, #f8fafc for dark mode]

*Note: Theme is managed via Tailwind CSS and `next-themes` for Dark/Light mode support.*

## 2. Fonts
- **Primary Font:** [e.g., Inter, Roboto, or system-ui]
- **Heading Font:** [e.g., Cal Sans, or same as Primary]

## 3. Typography
- **h1:** 2.25rem (36px), Bold, leading tight
- **h2:** 1.875rem (30px), Semibold
- **h3:** 1.5rem (24px), Semibold
- **p:** 1rem (16px), Regular, leading relaxed
- **small:** 0.875rem (14px), Regular text-muted
